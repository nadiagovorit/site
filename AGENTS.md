# Project rules — site (deploy repo)

## What this repo is

This repo is **build output only**. Its entire contents (`index.html`, `assets/`) are automatically generated by Vite from the source repo at **`F:\Disk F\site\site-source`** (sibling folder) and pushed here by the agent. It serves as the live site via GitHub Pages.

## Rules

- **Do not hand-edit any files in this repo.** If something looks broken on the live site, the fix must be made in `site-source` and rebuilt (`npm run build` writes directly into this repo).
- Do not ask the user to edit files here; the user is not technical.
- **Publishing only when the user explicitly asks.** The publish flow is:
  1. In `site-source`: `npm run build` (wipes and regenerates this repo's contents — expected and correct).
  2. Here: `git add -A`, commit with a short plain-language message, `git push origin main`.
  3. In `site-source`: commit and push source changes the same way.
- If `git status` here shows changes without a build having been run, be suspicious — rebuild before committing.
- Work directly on `main`, one commit per publish, never force-push.
